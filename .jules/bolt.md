## 2024-05-24 - [Unnecessary Polling Re-renders]
**Learning:** Polling mechanisms in React (e.g., `setInterval`) that update state with fresh API data on every tick cause full component tree re-renders, even if the data content hasn't changed. This is especially costly when the component tree is large or contains expensive child components (like `Cocina` with filtering/sorting).
**Action:** Use `useRef` to store the last known data state and perform a deep comparison (e.g., `JSON.stringify` for simple objects) before calling `setState`. This acts as a manual "memoization" for the state update itself. Also, be aware of stale closures in `setInterval` callbacks if dependencies aren't managed correctly; `useRef` can also solve this by providing stable access to the latest data.
